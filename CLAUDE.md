# invoice-ocr-to-excel

Собирает счета из PDF, сканов и фото в одну таблицу Excel: реквизиты, позиции, итоги. Суммы сверяются формулами, сомнительное подсвечивается.

## Структура

- `extract_invoices.py` — основной скрипт. PDF с текстом читается через pdfplumber, сканы и фото через Tesseract; перед OCR OpenCV стирает линии таблиц. Шаблоны поиска (`RE_HEAD`, `RE_SUPPLIER`, `RE_BUYER`, `RE_ITEM`, `UNITS`) собраны в начале файла.
- `gen_invoices.py` — генерирует тестовые счета с вымышленными реквизитами.
- `examples/` — 12 тестовых счетов и эталонный результат `Счета_сентябрь.xlsx`.

## Команды

```
pip install -r requirements.txt     # нужен Tesseract с русским языком
python extract_invoices.py examples/входящие_счета Счета.xlsx
```

На Windows путь к Tesseract задаётся переменной `TESSERACT_CMD`.

## Правила

- Работает только локально: документы никуда не отправляются, внешних API не добавлять.
- Не угадывать значения: если поле не распознано уверенно, строка помечается «проверить».
- После изменений прогнать на `examples/` и сравнить с эталоном: должно быть 10 счетов «ок» и 2 «проверить».
- Новые форматы документов поддерживаются правкой шаблонов в начале файла, а не отдельными ветками кода.
